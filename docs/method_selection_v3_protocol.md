# Method selection v3: prospective, training-evidence protocol

Status: **design only; no new holdout or v3 model call has been run**. The five v2 disease partitions and the complete TRANSCRIPT test labels have already influenced analysis. They are development evidence, not a fresh confirmatory holdout. The positive-only v2 amendment gave a negative result: DeepSeek feature-only selection 0.40653 versus fixed B2 0.51684 mean NS-AUC across five partitions (paired partition mean −0.11031; 0/5 wins). The original v2 protocol failed at partition 02 because one explicit negative could not be stratified. Preserve both records.

## Question and information boundary

Can a constrained LLM select among B0p, B1k, B1, and B2 **using only inner-training evidence** better than fixing B2 before a genuinely new outer test? V2 gave the model only label-blind dataset metadata; a method cannot learn which branch predicts labels from those features alone. V3 changes the information available, not the existing result.

For each new outer evaluation unit, first freeze its data provenance, inclusion criteria, evaluation unit, and splitter. The selector may receive only inner-CV scores computed on that unit's outer training set: per-method, per-fold NS-AUC, usable disease-row count, tie rate, training positive/negative counts, and uncertainty across folds. It must not receive outer labels, outer scores, full-dataset published performance on that same evaluation unit, or drug/disease identifiers that reveal the held-out answer. Record the exact serialized prompt, tool schema, model version, response, selected method, and provider-visible trace hash **before** any outer score is calculated.

## Predeclared comparison

1. Eligibility gate: require a source dataset independent of TRANSCRIPT's already analyzed disease partitions and enough positive/negative associations for the chosen official splitter and five inner folds. Keep explicit negatives under a single frozen policy; no post-failure relabeling. If the gate fails, report infeasible and do not tune the gate after inspecting outcomes.
2. Use identical outer splits, seed order, inner folds, label treatment, and official NS-AUC implementation for all four methods. Measure fixed B2, a deterministic training-only selector (highest mean inner NS-AUC; tie-break B2), and the LLM selector. A per-outer-test oracle is diagnostic upper bound only.
3. Freeze one LLM decision per outer evaluation unit. Repeated calls may measure prompt instability, but must be reported separately and must not allow best-of-repeat selection. Analyze paired outer NS-AUC differences against both baselines at the independent-unit level; seeds reusing one outer holdout are not independent replicates.
4. Primary endpoint: mean paired LLM-minus-B2 outer NS-AUC over independent evaluation units, with unit-level uncertainty. Secondary: LLM-minus-deterministic selector, selection frequencies, abstentions, trace-validation pass rate, latency and token cost. Report all units, including failures. Do not claim improvement from a positive mean on a single held-out dataset.
5. Before execution, commit the protocol, source checksums, unit IDs, label policy, eligible methods, tie/abstention rule, stopping rule, and output paths. Seal a choice file and verify every provider-visible trace against it before running outer outcomes. Never revise the frozen file in place.

## Agent result gate

The separate LUAD triage grader checks rank-to-source crosswalk consistency, candidate-versus-class citation scope, known GR contradiction coverage, identity-sensitive action gating, and structured research-only abstention on the **one historical adjudication**. The [versioned grade](../benchmark/results/luad_research_triage_v1_grade.json) and chained trace are retrospective; the saved response does not contain its own signature IDs, so the grader cannot claim the model independently identified those exact structures. It is not an independent Agent v4 holdout. A future holdout needs new, human-adjudicated cases with ambiguous formulation, false or class-only citations, contradictory evidence, unavailable tools, and insufficient-evidence outcomes. Freeze that case file before any model run. Report biomedical claim safety separately from routing accuracy (historical v3 DeepSeek 98/100) and from drug-prediction NS-AUC.
