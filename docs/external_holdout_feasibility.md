# Independent method-selection v3 holdout: source gate

Status: **partially staged, not yet runnable; no external model outcome has been calculated**. The read-only [source audit](../benchmark/results/external_holdout_source_audit.json) and its chained trace record the available upstream metadata. A sparse checkout at the pinned upstream revision staged all 233 CREEDS disease CSVs, CMap metadata and a gene mapping table under ignored local `artifacts/external/`; the [per-file SHA-256 manifest](../benchmark/results/external_staged_inputs_audit.json) records 227,110/227,110 finite gene/logFC rows and has its own chained trace. The five TRANSCRIPT disease partitions are already development data, so reusing them would not produce the independent confirmation required by the [v3 protocol](method_selection_v3_protocol.md).

The [CDRPipe comparative-analysis repository](https://github.com/enockniyonkuru/cdrpipe-comparative-analysis) currently tracks 233 CREEDS disease-signature CSVs and CMap drug experiment metadata (Git tree SHA `f5b358ec5f86c53a0043789bbcec0052c662c438`). Its raw CMap drug-expression matrix and Open Targets known-drug label parquet are **not in the audited Git tree**. The upstream README routes large data to a separate [Box release](https://ucsf.box.com/s/m54ipylmdytjsqmlp7axnabvjh2q8lwl) or Open Targets download; they still need staging, format checks, crosswalking, and a frozen label policy here. A disease list plus drug metadata is not enough to compute B0p/B1k/B1/B2 predictions or judge held-out associations. The alternative [TRACE dataset](https://data.mendeley.com/datasets/fy93xjjrb8/1) publishes three diseases and drug scores, but it does not supply a large set of independent disease-level units with the raw drug perturbation features and label policy needed for this predeclared comparison. Published drug scores cannot be substituted for features without changing the question and risking target leakage.

The next admissible run requires staging and hashing independent disease and drug expression matrices, explicit positive/negative indication labels, a documented drug/disease ID crosswalk, and sufficiently populated training folds. Then freeze inclusion and split rules, training-only inner-CV evidence, selector prompt and tie/abstention policy, and one prescore API choice per outer unit. Only after the choices and provider traces are sealed should outer B2 and selected-method scores be computed. This gate is a feasibility finding, not a negative or positive v3 performance result. The existing within-TRANSCRIPT v2 result remains the observed negative method-selection evidence.
