# 基于转录组与证据核验的药物重定位 Agent 课程设计报告

> 状态：可提交技术报告。课程任务 PDF 已核对：要求覆盖 Problem、Data、Model、Benchmark、Biological interpretation 五环节，提交 GitHub 代码并进行约 10 分钟汇报；PDF 未规定报告篇幅、封面或单独视频。本报告不构成临床建议。

## 摘要

本项目实现了一个可审计的药物重定位研究流程，将公开转录组数据、确定性药物排序、证据账本和可选结构化决策接口连接起来。外部评估采用 RECeSS/TRANSCRIPT v2.0.0 数据集；肺腺癌（LUAD）案例采用 GSE32863 配对肿瘤/邻近正常组织和 GSE92742 衍生的 ExperimentHub EH3226 A549 化合物扰动表达。系统记录输入哈希、筛选规则、排名、身份核对、引用状态及执行轨迹。三次随机拆分中，纯 Spearman 反转的全局 AUC 为 0.4820 ± 0.0108，低于训练折药物流行度基线的 0.7346 ± 0.0453；三次弱相关拆分中，预先固定的融合方法 AUC 为 0.4752。结果不支持该表达反转方案优于已有方法。LUAD 案例生成 4,920 个药名的表达排名，但前十名多为类固醇相关药物，并存在化合物身份不确定及临床证据不足问题，因此只作为实验研究假设。

**关键词：** 药物重定位；肺腺癌；转录组；LINCS L1000；证据溯源；Agent

## 1. 研究目标与边界

药物重定位希望为已有化合物寻找新的研究用途，但疾病表达与药物扰动表达的“反向”关系并不等同于患者获益。本项目的问题是：在公开基准上，表达反转是否带来可测的排序价值；以及能否把肺腺癌候选药物从数据处理追踪到可复核的证据记录。评价重点是数据边界、可复现性、与强基线比较及不确定性表述，而非制造新的临床疗法结论。

原计划包含 Jev 决策模型、通用 LLM、外部基准、内部 Eval、LUAD 端到端案例和课程展示。本阶段已实现确定性分析主流程、自然语言任务路由、受控工具调用、完整 Agent Trace、真实 DeepSeek 函数调用及可选 Jev 接口。冻结的 61 项 v2 路由集上，修改前规则为 35/61，原始 DeepSeek 为 55/61；根据失败类型加固后的结果只作为回归验证。另建的 100 项 v3 独立 holdout 在任何调用前提交，规则规划器为 90/100，一次 DeepSeek Flash 调用为 98/100，且未根据失败修改系统。TypeSafe Jev 仍无凭据和真实结果。

## 3. 方法

### 3.1 疾病差异表达

对已归一化且取 log2 的表达矩阵进行同一患者的肿瘤减正常分析。初始实现为配对 t 检验、Benjamini–Hochberg 校正，预设阈值为 FDR < 0.05 且 |log2FC| ≥ 1。随后使用 R 4.6.1、Bioconductor limma 3.68.5 以患者固定效应设计矩阵运行 `lmFit` 和 `eBayes` 敏感性分析。两者得到相同的阈值基因集：上调 512 个、下调 749 个；log2FC 在数值精度内一致。limma 对方差进行经验贝叶斯调整，因此 p 值和 FDR 不要求逐项相同。

### 3.2 转录组候选排序

药物与疾病向量按明确基因 ID 对齐。方法 B1 为负 Spearman 相关系数；LUAD 案例另计算疾病上调基因在药物下调端、疾病下调基因在药物上调端的秩连接分数。各分数通过固定 `k=60` 的 reciprocal-rank fusion（RRF）合并，并列分数使用相同平均名次，避免输入行顺序成为隐含先验。LUAD 仅使用 961 个重合的 LINCS landmark 基因，其中预设显著上调 57 个、下调 50 个。候选排名不读取已知治疗药物标签或 Broad 注释。

### 3.3 外部基准

在 `stanscofi` 2.0.1 的随机简单拆分与弱相关拆分上，采用 20% 外层测试比例并调用其全局 AUC/NDCG 定义。项目方法包括随机 B0、训练折药物流行度 B0p、表达反转 B1、表达近邻传播 B1k、固定融合 B2。B1k/B2 使用三个外层种子和三折内层调参。ALSWR、PMF、LogisticMF 使用五个外层种子 1234 至 1238，并在每个外层训练折内完成三折调参。十次官方模型运行均报告零外层测试坐标进入内层 CV，预测对象的评分矩阵全部置零。未知的 `0` 按官方全局 AUC 惯例归入非正类，但不解释为临床失败。

## 4. 结果

| 方法 | 随机拆分 AUC（均值 ± SD） | 弱相关拆分 AUC（均值 ± SD） |
| --- | ---: | ---: |
| B0 随机 | 0.5363 ± 0.0061 | 0.5049 ± 0.0419 |
| B0p 训练折流行度 | 0.7346 ± 0.0453 | 0.5000 ± 0.0000 |
| B1 负 Spearman | 0.4820 ± 0.0108 | 0.5238 ± 0.0000 |
| B1k 表达近邻 | 0.5660 ± 0.0102 | 0.5108 ± 0.0000 |
| B2 固定 RRF | 0.7270 ± 0.0417 | 0.4752 ± 0.0000 |
| ALSWR 默认 | 0.6253 ± 0.0110 | 0.6481 ± 0.0000 |
| PMF 默认 | 0.6075 ± 0.0242 | 0.5656 ± 0.0031 |
| LogisticMF 默认 | 0.8005 ± 0.0308 | 0.6696 ± 0.0495 |

随机拆分中 B1 近于或低于机会水平，B2 没有超过 B0p；弱相关拆分中 B2 的 AUC 低于 0.5，LogisticMF 表现更好。弱相关拆分的确定性方法在三个种子中得分相同，提示折划分可能重复，不能把零标准差解释为结果稳定。

嵌套调参后，B1k 在随机拆分的外层 AUC 提高到 0.6206 ± 0.0060，B2 为 0.7371 ± 0.0384；弱相关拆分分别为 0.5140 和 0.4702 ± 0.0079。调参没有解决对不相似药物的泛化问题，LogisticMF 仍是本项目测试中最强的基线。

五外层种子的嵌套结果显示，ALSWR、PMF、LogisticMF 在随机拆分的 AUC 分别为 0.6579 ± 0.0320、0.6161 ± 0.0211 和 0.7826 ± 0.0410；弱相关拆分分别为 0.5922 ± 0.0528、0.5654 ± 0.0036 和 0.6474 ± 0.0678。LogisticMF 仍领先，但弱相关切分的波动较大，单次默认参数结果会高估稳定性。

LUAD 表达筛选前十名依次是 hydrocortisone、beclomethasone-dipropionate、clocortolone-pivalate、mometasone、flumetasone、BRD-K84203638、hydrocortisone-hemisuccinate、fluorometholone、fluticasone、diflorasone。预先冻结的 11 个参考药名只有 5 个可在该 A549 子集中测得；其中 docetaxel 排 106、crizotinib 排 241，其他三个可测参考药排得更低。其余六个参考药名未测得，不能当作排序失败。

复现 EH3226 上游 `sig_filter` 的源文件顺序去重规则后，前十候选均恢复出唯一 `sig_id` 和 `pert_id`，并得到 GSE92742 的 InChIKey 与结构字段。逐签名来源因此明确，但与 Broad Hub 交叉核对时仍只有两个精确 InChIKey 匹配；其余包括立体化学差异、结构不符、同义词或没有 Hub 样品。候选级证据矩阵显示九个名称属于或很可能属于糖皮质激素类，主要指向 NR3C1/糖皮质激素受体转录。hydrocortisone 有 A549 生长抑制和独立计算候选背景，beclomethasone-dipropionate 有 A549 中 GR 依赖的 CYP3A5 诱导；类别级研究也报告化疗保护、干性与免疫治疗背景下的不利信号。其余多数候选没有药物特异 LUAD 疗效证据。十个候选均保持“证据不足”。

## 5. 系统实现与审计

系统包含自然语言 Planner、允许列表工具 Schema、表达数据读取与 QC、差异表达、排序、RECeSS 适配器、药物身份核对、文献分诊、证据账本和 LUAD 案例打包器。Planner 只接收模式和可用输入名称，不接收原始矩阵、文件路径或 Benchmark 标签；DeepSeek 返回的调用还须经过工具名、参数、输入和模式权限验证，不可用工具会失效关闭到人工复核。全部状态写入 `agent_run.json`。可选 Jev 适配器仍没有真实凭据或结果。

Python 3.10 的 Benchmark 测试依赖记录在 `requirements-benchmark.lock`。当前环境中 32 项内部测试通过，并另有 20 项 v1、61 项 v2 和 100 项 v3 Planner Eval。`data/manifests/` 记录公开来源和本次文件哈希；完整表达矩阵保存在 Git 外。数据卡、系统卡、限制说明和执行步骤见 `docs/` 与根目录 README。

## 6. 局限与后续工作

本项目的表达反转指标在公开基准上没有取得领先结果，提示基于转录组的单一对抗方向不足以代表药物与疾病的真实治疗关系。LUAD 案例只有单一 A549 细胞系、固定剂量与时间；逐签名 ID 已恢复，但交叉来源的盐型、立体化学和同义词问题仍需实物核验。前十名的类固醇集中也可能反映共同转录反应。候选级文献矩阵已记录支持与反对信号，但它是有边界的人工分诊而非系统综述，且类别证据不能替代候选药特异验证。没有足够证据把任何候选推荐给患者。

下一阶段需按已冻结的实验方案采购和核验化合物，完成剂量、LUAD 亚型、NR3C1 依赖和联合用药实验。若获得 Jev 访问权限，再与规则和 DeepSeek 比较准确率、校准、延迟和成本。课程 PDF 已完成核对；本次将把 v3 holdout、五种子嵌套 CV、逐签名 ID 和实验边界纳入约 10 分钟答辩材料并重新做视觉检查。
