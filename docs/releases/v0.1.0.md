# v0.1.0 基线版本

冻结日期：2026-09-24

用途：作为后续 Agent、LLM、Jev、证据层和 Benchmark 改进的固定对照版本。后续实验不得覆盖本版本结果，应使用相同数据、拆分、随机种子和指标与该 tag 比较。

## 冻结范围

- 自然语言任务入口与规则 Planner；
- 外部结构化 LLM Planner 的工具调用适配边界；
- 工具白名单、参数校验及 Benchmark Strict / Research Open 权限；
- TRANSCRIPT 表达反转、Connectivity、RRF 和 RECeSS 适配器；
- 已保存的三种子 Benchmark 结果；
- GSE32863 与 EH3226 A549 的 LUAD 表达筛选；
- 候选身份审计、证据账本、执行轨迹和限制说明；
- 课程报告及九页答辩稿；
- 23 项内部测试。

## 基线结论

- TRANSCRIPT 随机拆分中，B1 负 Spearman 的全局 AUC 为 `0.4820 ± 0.0108`，B0p 训练折流行度为 `0.7346 ± 0.0453`，LogisticMF 默认参数为 `0.8005 ± 0.0308`。
- 当前表达反转方法没有超过强基线，不能宣称 SOTA。
- LUAD Top-10 只是表达筛选假设；化合物身份和临床证据尚不足，不能作为治疗建议。

## API 与模型调用边界

- 默认 Agent 使用规则 Planner，不调用外部模型。
- `StructuredPlanner` 只完成结构化 LLM 工具调用接口和模拟安全测试，尚未连接真实通用 LLM。
- Jev Choice、Score、Noul 适配器及失败降级已实现，但没有 TypeSafe 凭据，因此没有真实 Jev 准确率、校准、延迟或成本结果。
- Benchmark 结论来自确定性代码、公开数据、官方拆分与评分函数，不依赖 LLM/Jev API。
- 已保存的文献检索与身份注释来自数据源脚本和冻结文件；未完成的人工证据审阅仍标记为未完成。

## 后续版本比较规则

1. 保留本 tag，不修改本版本文件或结果 JSON。
2. 使用相同的 TRANSCRIPT 版本、拆分协议和种子比较 Benchmark 指标。
3. LLM/Jev 比较使用冻结决策集，并分别记录准确率、失败率、延迟、调用次数和成本。
4. LUAD 候选只有在完成身份、支持证据、反对证据和安全性核查后才能升级证据等级。
5. 每个新版本先运行全部内部测试，再生成与 `v0.1.0` 的差异报告。
