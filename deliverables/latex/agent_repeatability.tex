\textbf{结论}

\begin{itemize}
\tightlist
\item
  一旦工具计划确定，计算完全可复现：所有完成的运行输出同一个 RRF
  矩阵（哈希一致，Spearman = 1.0），因为排序由确定性工具完成，LLM
  不接触数值。
\item
  差异只出现在``理解请求''这一步：规则规划器无法识别第 5 种说法（``请对
  TRANSCRIPT
  数据运行表达反转并输出排名矩阵''），两次都安全地转人工审核，完成率
  0.8，未达 0.9 门槛；DeepSeek 10/10 完成，计划始终为同一个工具调用。
\item
  失败方式是保守的（转人工），没有执行错误工具。这与 100 例冻结 holdout
  中规则 90/100、DeepSeek 98/100 的差距方向一致。
\item
  局限：只测了一种任务、5 种说法、每种 2 次；DeepSeek 在 temperature 0
  下的稳定性不代表更换模型版本后的表现。
\end{itemize}
