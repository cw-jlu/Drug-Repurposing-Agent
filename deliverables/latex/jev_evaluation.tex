\subsection{结论}\label{ux7ed3ux8bba}

\begin{itemize}
\tightlist
\item
  \textbf{Jev 准确率最高、Brier 最低}：不加门控时准确率
  0.900，高于规则与两个 DeepSeek 模型；Brier 0.147 明显低于
  flash（0.221）与 v4-pro（0.228）。但单看校准误差
  ECE，flash（0.025）略好于
  Jev（0.042），v4-pro（0.107）最差，所以不能说 Jev
  在所有校准指标上都最好。数据质量评分的 Spearman 以 Jev 最高（0.929）。
\item
  \textbf{Jev + 门控把高风险误执行降到 0}（flash + 门控为 0.083，v4-pro
  门控从不触发），代价是升级率升至 0.483。J4 把低置信判断交给 flash
  后，准确率回到 0.867，高风险误执行 0.067，介于两者之间。
\item
  \textbf{混合设计对判断器不敏感}：v2
  中``规则算结构化字段、模型只判备注''的混合层，无论 flash、v4-pro 还是
  Jev 判备注，高风险误执行都是 0（Jev 39/40）。
\item
  \textbf{让模型包办整个决策不稳}：完整 Jev 只有
  32/40，且出现高风险误执行；完整 v4-pro
  也出现了。这再次支持``模型只做封闭的窄判断''的分工。
\item
  给混合层再叠加置信门控会过度保守（无风险备注 0.350
  被转人工），不建议在 v2 这类备注判断上使用。
\item
  延迟：Jev 单次约 1048 ms，与 flash 相近，明显快于
  v4-pro。免费模型，未计成本。
\item
  局限：用例为按成文策略生成的合成数据，每组一次运行；免费版模型可能与付费版不同。
\end{itemize}
