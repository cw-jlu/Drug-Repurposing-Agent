\textbf{结论}

\begin{itemize}
\tightlist
\item
  训练折\textbf{疾病流行度}贡献最大：去掉后下降 0.063，10/10
  个种子都变差。
\item
  单独最强的是两个\textbf{标签共现协同过滤}（LD 0.702、LS
  0.700）。去掉其中任意一个约降 0.016，说明二者有互补信息。
\item
  \textbf{表达反转}单独只有 0.486，与随机无差别；去掉它只降 0.008，且
  3/10
  个种子反而更好。它在融合中的作用接近打破同分，而不是提供药理信号。
\item
  疾病表达 kNN（SK）几乎可去掉（−0.0025，4/10 更好）。
\item
  合起来：B3 的提升来自已知关联结构（流行度 +
  标签共现），转录组特征贡献很小。这与 TRANSCRIPT
  上``反转≈随机''的主结论一致。
\end{itemize}
