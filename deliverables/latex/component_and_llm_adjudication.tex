\section{Decomposed B2 prediction and bounded LLM research
triage}\label{decomposed-b2-prediction-and-bounded-llm-research-triage}

These are two distinct experiments. The first measures drug--disease
ranking accuracy on TRANSCRIPT. The second asks an LLM to prioritize
\textbf{next research actions} for the frozen LUAD Top-10. Its output is
not a drug efficacy score and must not be merged with the NS-AUC table.

\subsection{B2 component ablation}\label{b2-component-ablation}

The frozen B2 model is an unweighted reciprocal-rank fusion of three
inputs: \texttt{B0p} (training-fold positive count per drug),
\texttt{B1k} (drug-expression kNN propagation of training-fold positive
labels), and \texttt{B1} (negative Spearman correlation between drug and
disease expression signatures). The component adapters in
\texttt{benchmarks/\allowbreak{}recess\_\allowbreak{}adapter/\allowbreak{}official\_\allowbreak{}components.\allowbreak{}py} exactly
match the corresponding frozen \texttt{TranscriptBaseline} scores in
unit tests; changing validation ratings leaves their scores unchanged.
\texttt{B0p} and \texttt{B1k} use only training-fold associations.

The adapters enter the same pinned
\href{https://github.com/RECeSS-EU-Project/benchmark-code}{RECeSS
official runner} as B2, using 100 identical seed values, a 20\% outer
holdout, five inner folds, and the author\textquotesingle s NS-AUC
calculation for both split types. The second patch is applied
\emph{after} \texttt{official\_\allowbreak{}b2.\allowbreak{}patch} and does not modify
B2\textquotesingle s implementation. The published five-fold operation
selects the best fold-trained model by inner row-wise AUC; it does not
search a hyperparameter grid. The weakly correlated split repeats one
outer holdout across seeds, so its spread is not uncertainty over 100
distinct outer splits.

To reproduce, apply both patches to a clean clone at commit
\texttt{a7f11077271ced\allowbreak{}f3a98a82e3dc74\allowbreak{}b6fc0e93986e}, then run:

\DataTypeTok{python} \OperatorTok{{-}}\NormalTok{m scripts}\OperatorTok{.}\FunctionTok{compare\_recess\_components}
\end{Highlighting}

The comparison checks all 100 seed positions, finite metrics, pairwise
B2 differences, and source hashes. It writes
\texttt{benchmark/\allowbreak{}results/\allowbreak{}recess\_\allowbreak{}official\_\allowbreak{}component\_\allowbreak{}ablation.\allowbreak{}json}.

Values are means ± sample SD over 100 upstream metric values. On random
simple, B2 exceeds B1 by 0.0407 paired NS-AUC points and wins 97/100
seeds; on weakly correlated, B1 exceeds B2 by 0.0398 and wins 100/100
seeds. The weak-split B1 zero SD reflects the same deterministic outer
holdout, \textbf{not} evidence of negligible uncertainty. The B1k
adapter was additionally checked against the frozen
\texttt{TranscriptBaseline} on the real TRANSCRIPT first random split;
all three component score vectors matched exactly (maximum absolute
difference 0). The very low B1k NS-AUC is therefore not explained by an
adapter score mismatch, though the dataset/metric cause has not been
proven. The versioned aggregate CSVs and parameter files are in
\texttt{benchmark/\allowbreak{}results/\allowbreak{}recess\_\allowbreak{}official\_\allowbreak{}components/\allowbreak{}}.

The B0p random run was resumed after changing only \texttt{njobs} from 1
to 4: the official runner reused the first 14 completed seed
intermediates and computed the rest in parallel. Both parameter receipts
are retained. Seed order, model code, folds and metric were unchanged;
\texttt{njobs} affects execution scheduling only.

Before inspecting component ablation results, one accepted DeepSeek
Flash call chose a method from the four frozen options using only the
versioned method, split, and dataset descriptions in
\texttt{configs/\allowbreak{}component\_\allowbreak{}selector\_\allowbreak{}v1.\allowbreak{}json}. It selected \texttt{B2}
for random simple and \texttt{B1} for weakly correlated. The choices,
input hash, timestamp and token usage were committed in
\texttt{benchmark/\allowbreak{}results/\allowbreak{}recess\_\allowbreak{}component\_\allowbreak{}llm\_\allowbreak{}selector\_\allowbreak{}v1.\allowbreak{}json} at
\texttt{fbd9858} while the component runs were still in progress. An
earlier strict-tool response failed the local reason-length check and
was not saved; the accepted retry still preceded inspection of ablation
scores. This is a single prescore choice, not a tuned classifier or a
reliable estimate of method-selection skill. After the run, both choices
rank first among these \textbf{four} methods: selected NS-AUC is 0.5222
for random simple and 0.5417 for weakly correlated. Relative to always
using B2, the latter is +0.0398 on the same repeated outer holdout.
There are only two split-level decisions, no candidate- or
disease-specific LLM routing and no independent model-selection holdout.
This result cannot support a claim that LLM selection generally improves
prediction or beats the published 11-model panel. The
model\textquotesingle s random-split rationale described B0p/B1k label
signal as reliable, but their observed NS-AUCs were 0.5000 and 0.1747.
Thus even its successful method choice came with a partly unsupported
explanation. The reasoning text must not be treated as an interpretation
of the measured result.

\subsection{LLM evidence triage}\label{llm-evidence-triage}

\texttt{scripts/\allowbreak{}run\_\allowbreak{}luad\_\allowbreak{}llm\_\allowbreak{}adjudication.\allowbreak{}py} reads the frozen
\texttt{configs/\allowbreak{}luad\_\allowbreak{}top10\_\allowbreak{}evidence\_\allowbreak{}v1.\allowbreak{}json} and the human-reviewed
\texttt{docs/\allowbreak{}luad\_\allowbreak{}top10\_\allowbreak{}evidence\_\allowbreak{}matrix.\allowbreak{}md}. It does not read
TRANSCRIPT labels or benchmark predictions. DeepSeek Flash is asked for
one to three \textbf{research actions}, each tied to an existing rank
and supplied PMID. A strict function schema and a local validator reject
unknown drugs, fabricated/mis-scoped PMIDs, unknown actions, duplicate
ranks, clinical actions, and an assay recommendation for a cross-source
identity-unresolved compound. All ten evidence tiers remain
\texttt{insufficient\_\allowbreak{}evidence}; model prose is advisory and unverified.

The real call used the
\href{https://api-docs.deepseek.com/guides/tool_calls/}{DeepSeek strict
tool-call mode} on 2026-09-26. Two earlier JSON-mode responses failed
local validation and were not accepted or saved. The one accepted
response prioritized rank 6 \texttt{BRD-K84203638} and rank 5
\texttt{flumetasone} for identity resolution, and rank 2
\texttt{beclomethasone-dipropionate} for literature review. It did not
propose a treatment or claim efficacy. The validated output and input
hashes are saved in
\texttt{benchmark/\allowbreak{}results/\allowbreak{}luad\_\allowbreak{}llm\_\allowbreak{}adjudication\_\allowbreak{}v1.\allowbreak{}json}. This is
\textbf{one model sample}, not a blinded accuracy estimate or proof that
its prioritization is optimal.

Run it again only with a local \texttt{DEEPSEEK\_\allowbreak{}API\_\allowbreak{}KEY} or an ignored
\texttt{.\allowbreak{}env} file:

The key is never written to the result. Repeated model calls and blinded
human review would be needed to quantify decision consistency and
evidence quality.

\subsection{Planner v3 is a separate
metric}\label{planner-v3-is-a-separate-metric}

Agent v3\textquotesingle s 98/100 is exact-match selection of the
expected tool on a frozen 100-case set; it does not grade drug
predictions. Its two failures are \texttt{v3\_\allowbreak{}luad\_\allowbreak{}003}
(\texttt{package\_\allowbreak{}luad\_\allowbreak{}case} expected, \texttt{manual\_\allowbreak{}review}
selected) and \texttt{v3\_\allowbreak{}boundary\_\allowbreak{}004} (\texttt{manual\_\allowbreak{}review}
expected, \texttt{rank\_\allowbreak{}transcriptome} selected). Both were valid tool
calls, not API errors. The stored trace has no raw model reasoning, so
their internal cause cannot be determined from this run. See
\texttt{docs/\allowbreak{}planner\_\allowbreak{}eval\_\allowbreak{}results.\allowbreak{}md}.
