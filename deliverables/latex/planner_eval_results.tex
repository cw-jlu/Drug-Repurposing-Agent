\subsection{失败与波动}\label{ux5931ux8d25ux4e0eux6ce2ux52a8}

\begin{itemize}
\tightlist
\item
  \texttt{rank\_\allowbreak{}zh\_\allowbreak{}02} 在两次运行中被过度保守地转为人工复核；
\item
  \texttt{rank\_\allowbreak{}zh\_\allowbreak{}01} 在一次运行中被转为人工复核；
\item
  \texttt{strict\_\allowbreak{}luad\_\allowbreak{}02} 在一次运行中选择了 Strict
  模式允许的表达排名，而人工标签要求人工复核；
\item
  第三次运行为 20/20，不能只报告这一最好结果。
\end{itemize}

这说明 DeepSeek 比简单关键词规则更准确，但单次工具选择仍有随机波动。当前
20 个案例规模较小，只能支持``初步改善''的结论，不能据此宣称稳定达到
93.3\% 的总体准确率。

\texttt{manual\_\allowbreak{}review}、实际
\texttt{rank\_\allowbreak{}transcriptome}。两次返回均是有效工具调用，没有 API 或
Schema 错误。结果 JSON

v3 是一次真正的独立 holdout，但只有一次 DeepSeek 抽样，98\%
不能解释为稳定总体准确率。后续若要估计随机波动，应保持该文件不变并增加重复调用，不能再根据
v3 失败调整同一评测结论。
