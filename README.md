# Drug Repurposing Agent

An auditable agent for transcriptomic drug repurposing, biomedical evidence retrieval, and structured decision routing with Jev.

The project is currently at the planning stage. The implementation, internal eval suite, and external benchmark results have not yet been produced.

Read the [full project plan](./药物重定位Agent项目计划.md) for the data sources, file formats, preprocessing steps, benchmark protocol, agent architecture, evaluation metrics, milestones, and known limitations.

The main external evaluation is planned around the public [RECeSS drug repurposing benchmark](https://github.com/RECeSS-EU-Project/benchmark-code) and its [TRANSCRIPT v2.0.0 dataset](https://zenodo.org/records/7982976). A separate lung adenocarcinoma case study is planned using [GSE32863](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE32863) and [LINCS GSE92742](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE92742).

Raw datasets are not included in this repository. The plan records their official sources and verification requirements.
